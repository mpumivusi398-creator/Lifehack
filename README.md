Lifehack Quiz App
Project Overview
The Lifehack Quiz App is a multi‑screen Android application built in Kotlin.  
It provides a fun and interactive quiz experience with a colorful pastel UI, score tracking, and a review screen where users can check their answers against the correct ones.


 🎨 Features
- Welcome Screen: Cheerful pastel yellow background with a start button.
- Quiz Screen: Calm pastel blue background with 15 True/False questions.
- Score Screen: Soft pastel purple background showing the user’s score.
- Review Screen: Scrollable pastel blue background listing all questions, user answers, and correct answers.


 Project Structure
- `MainActivity.kt` → Welcome screen logic  
- `QuizActivity.kt` → Quiz logic, question handling, score tracking  
- `ScoreActivity.kt` → Displays final score and links to review  
- `ReviewActivity.kt` → Shows user answers vs correct answers  
- `res/layout/` → XML layouts for each screen  
- `res/values/colors.xml` → Pastel color palette  
- `res/values/themes.xml` → App theme configuration
